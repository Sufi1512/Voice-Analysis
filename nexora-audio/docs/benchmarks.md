Generated by `python benchmarks/sessions.py --seconds 20` on 2026-11-13.
Processing time only (no network or codec I/O beyond the session). One session = one caller.

Machine: x86_64, 2 logical CPUs, Python 3.13.18, 20 s of audio per session, 20 ms chunks

**Reading it:**
- *Sessions per core* = 1 / (CPU seconds per audio second). Keep about 30% headroom:
  plan for roughly **4 concurrent calls per core** with the default DeepFilterNet3 pipeline,
  or **10 per core** with `noise_backend="rnnoise"`.
- Sessions run in parallel across cores: the native backends release the GIL, so two
  sessions on two cores take about the same wall time as one (last column).
- p99 per 20 ms chunk stays well below 20 ms, so processing never falls behind real time.

Where the time goes (default pipeline): DeepFilterNet3 inference is about two thirds.
The rest is the voice enhancer, two Silero VAD instances (one gates suppression, one
drives turn events) and resampling. Integer-ratio resampling (8/16 <-> 48 kHz) uses
SciPy's compiled FIR filter.
