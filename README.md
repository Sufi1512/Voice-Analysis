# Voice-Analysis — Krisp.ai investigation workspace

Evidence-backed study of Krisp.ai's observable product behaviour and documented
developer contracts, used to design an independent voice-AI platform
(meeting assistant, call-center AI, real-time audio engine).

- `CLAUDE.md` — rules for Claude Code in this repo
- `INVESTIGATION_MASTER_PLAN.md` — modules, questions, completion criteria
- `EVIDENCE_LEDGER.csv` — one row per observation
- `templates/` — evidence entry and module report templates

Never commit credentials, cookies, raw HAR files or real meeting content.
